# برنامج قسم الإظهار الكيميائي

مصدر البرنامج محفوظ هنا كملفات نصية، والسكربت `Build-App.ps1` يبني منها ملف أكسس (`.accdb`) جديدًا على جهازك.

## المحتويات

| المسار | المحتوى |
|---|---|
| `src/app.json` | 19 جدولًا بحقولها وتسمياتها وقواعد التحقق، و35 فهرسًا، و21 علاقة، والبيانات الأساسية (المستخدمون، الجهات، أنواع الحوادث، الأجهزة، المواد...)، و21 استعلامًا |
| `src/modules/*.bas` | وحدات الكود: `modApp` و`modReport` و`modDashboard` (UTF-8) |
| `src/forms/*.txt` | النماذج الـ13. تُنشأ تلقائيًا أول مرة من ملفك الحالي |
| `Build-App.ps1` | سكربت البناء |
| `Build.cmd` | لتشغيل السكربت بالنقر المزدوج |

## المتطلبات

- ويندوز مع Microsoft Access مثبت (2016 أو أحدث).

## أول تشغيل (مع استيراد النماذج من ملفك الحالي)

النماذج لا يمكن استخراجها إلا بأكسس نفسه، لذلك في أول مرة أعطِ السكربت مسار ملفك الحالي:

```
powershell -ExecutionPolicy Bypass -File Build-App.ps1 -SourceDb "C:\المسار\ملفك.accdb"
```

السكربت ينسخ النماذج من ملفك ويحفظها نصيًا في `src\forms`، فلا تحتاج `-SourceDb` بعد ذلك.

## التشغيلات التالية

انقر مرتين على `Build.cmd`، أو:

```
powershell -ExecutionPolicy Bypass -File Build-App.ps1 -Force
```

الناتج: `build\الإظهار الكيميائي.accdb`. لاختيار مسار آخر: `-Output "D:\برنامج.accdb"`.

بعد البناء افتح الملف، ثم من محرر VBA (Alt+F11) اختر **Debug > Compile** للتأكد من سلامة الكود.

## ملاحظات

- مجلدا `assets` (قالب التقرير والتواقيع) و`التقارير` لا يدخلان في البناء. انسخهما بجانب الملف الناتج كما في برنامجك الحالي.
- تُنقل كل البيانات الموجودة في الملف وقت الاستخراج. جداول القضايا والمجموعات والعينات والآثار والتشغيل وحركات المخزون كانت فارغة، فتُبنى فارغة.
